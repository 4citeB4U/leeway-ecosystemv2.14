## Mandatory Rules

- RF_RULE_01: LeeWay-Standards owns law. Runtime Fabric enforces law. Agent Lee operates under law.
- RF_RULE_02: Runtime Fabric may not execute, mutate, route live work, call models, control devices, post externally, or package unless a later exact owner approval and receipt-bound single-use gate permits it.
- RF_RULE_03: Discovery is closed as present, reassembled, bound, and status-proven by 436 through 439; it is no longer treated as missing.
- RF_RULE_04: Docker containers are classified but blocked. Active scope is locked structurally, not approved for execution.
- RF_RULE_05: Backup, rollback, exited, or document-only containers cannot become primary active authority.
- RF_RULE_06: No docker exec is allowed in governance, proof, or packaging lanes unless a future policy explicitly permits it; current state blocks it.
- RF_RULE_07: No Docker mutation is allowed: no start, stop, restart, build, compose up/down, rm, prune, or image/package generation.
- RF_RULE_08: Voice, image, model, provider, browser, Telegram, and physical/device action surfaces remain high-risk blocked.
- RF_RULE_09: Canonical evidence belongs in E: Archive/proofs and runtime records, not primarily inside replaceable Docker containers.
- RF_RULE_10: Packaging and SDK distribution remain paused until execution proof and packaging gate close cleanly.
