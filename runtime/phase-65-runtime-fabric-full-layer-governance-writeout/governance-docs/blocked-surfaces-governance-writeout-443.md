# Blocked Surfaces Governance Writeout - 443

## Blocked Runtime Fabric Surfaces

The following surfaces remain blocked unless a later exact owner approval and receipt-bound proof gate permits a narrower action:

- Runtime execution
- Agent Lee runtime execution
- Container execution
- Docker exec
- Docker mutation
- Docker start/stop/restart/build/compose up/down/rm/prune
- Device control
- Physical action
- Telegram posting
- Model/provider calls
- Tool execution
- Browser control
- Image generation
- Voice generation
- Package creation
- SDK distribution
