# Agent VM Technical Specification

## Runtime Environment
The Agent VM is a virtualized workstation environment rendered inside the Leeway Construct. It provides the following subsystems:

1. **LeeCode (VScode-lite)**: For document processing and code-based task execution.
2. **Browser**: For knowledge retrieval and external web interaction.
3. **Terminal**: For package management (Scripting, Linux envs).
4. **Pallium Memory Lake**: An 8-drive file-memory fabric for long-term retention.
5. **Database Explorer**: For structured relational data management.

## Isolation Standards
- **Private Namespace**: Every VM has an isolated VFS (Virtual File System).
- **Communication Scope**: Restricted to verified MCP (Model Context Protocol) routes.
- **Revocation**: Instant state termination via the Leeway LawEngine.
