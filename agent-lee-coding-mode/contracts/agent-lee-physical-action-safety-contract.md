# Agent Lee Physical Action Safety Contract

## Purpose

Define safe approval-gated behavior for physical-world actions.

## Actions Requiring Explicit Approval

- Printing.
- Scanner use.
- IoT control.
- Locking or unlocking devices.
- Sending messages to phones.
- Changing phone or device settings.
- Turning cameras or microphones on for monitoring.
- Changing printer or device configuration.
- Deleting print queue jobs.

## Rules

- Explain the intended physical-world action first.
- Ask Leonard for approval before execution.
- Write a receipt for the approval and the execution.
- Report blockers honestly.
