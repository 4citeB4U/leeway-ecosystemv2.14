# Research Notes

This research set supports the 3D chess proof and keeps the claims grounded.

## Sources

- FIDE Laws of Chess: official rules reference for legal moves, castling, promotion, and draw logic.
- FIDE article / handbook pages: useful for touch-move, castling, and promotion details.
- Stockfish official site and blog: engine evaluation and search concepts, including NNUE and alpha-beta style search.
- Three.js docs and manual: scene, camera, materials, examples, and glTF loader references.
- Babylon.js WebXR and glTF docs: WebXR and asset import path for AR-ready browser scenes.
- Britannica Bobby Fischer profile: historical anchor for grandmaster-level aura and public chess identity.

## What I used from the sources

- The board stays 8x8, legal moves are piece-specific, and promotions / castling remain explicit rule surfaces.
- Engine language in the UI references evaluation + search rather than pretending a superhuman engine is already plugged in.
- The scene manifest is marked WebGL/WebXR-ready, but the true GLB and device AR backend is still guarded.
- The themed families are designed as distinct visual identities, not simple palette swaps.

## Inference notes

- The exact piece art style is a design inference, not a cited rule.
- The 3D composition is a browser-native proof pattern inferred from Three.js / Babylon.js scene design, not a claim of a fully exported mesh pipeline.
