## Real/Proven 3D Rule
A 3D asset is not REAL/PROVEN until a GLB/OBJ/FBX is generated or validated, has geometry, file size, and a receipt.

## Neural Reconstruction Rule
Neural Reconstruction requires a real backend such as TripoSR, InstantMesh, Unique3D, or another local image-to-3D engine. Procedural fallback cannot be labeled neural.
