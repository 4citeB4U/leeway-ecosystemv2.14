## Major runtime lanes

- `agent-lee-coding-mode` for orchestration, runtime, desktop, voice, and discovery.
- `Leeway Runtime Fabric` for governed runtime, receipts, manifests, registries, adapters, and proof.
- `agent-lee-voice-kernel` for the canonical voice lane.
- `LeeWay-Standards` for governing law, contracts, and canonical truth.

## Operational truth

- Qwen 3 remains the primary local language model lane unless standards and creator authority say otherwise.
- Qwen 3V / Qwen-VL remains the vision lane through the local Ollama/Docker route.
- Agent Lee Voice Kernel owns voice generation.
- Desktop runtime is playback and device-action plumbing, not voice ownership.
- Any absent or unreachable route must be reported as unavailable, not invented.

## Source priority

1. User-provided instructions and uploads.
2. LeeWay Standards files.
3. Local runtime manifests, receipts, reports, and logs.
4. Runtime source code and scripts.
5. External sources only when local evidence is missing.

## Evidence expectation

When making runtime claims, verify with:

- manifests
- route probes
- receipts
- reports
- logs
- source files

Do not claim readiness from folder names alone.
