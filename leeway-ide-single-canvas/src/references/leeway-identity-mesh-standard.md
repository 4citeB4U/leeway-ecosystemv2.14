# LeeWay Identity Mesh Standard

LeeWay is the operating physics of the agentic hive. IDs are not labels; they are traceable identity records.

## Required ID Families

- `LEEWAY_APP`
- `LEEWAY_ACTOR`
- `LEEWAY_INTENT`
- `LEEWAY_PROMPT`
- `LEEWAY_TX`
- `LEEWAY_GATE`
- `LEEWAY_EVENT`
- `LEEWAY_CMD`
- `LEEWAY_FILE`
- `LEEWAY_ARTIFACT`
- `LEEWAY_EVIDENCE`
- `LEEWAY_RECEIPT`
- `LEEWAY_ATTEST`
- `LEEWAY_POLICY`
- `LEEWAY_AUTHORITY`
- `LEEWAY_QUARANTINE`
- `LEEWAY_TRACE`

## Record Requirement

No LeeWay action is valid unless the actor, prompt, intent, transaction, node, authority, gate, evidence, and receipt are all identifiable and traceable.

Every real LeeWay ID must resolve to an identity record with source, actor, intent, transaction, classification, ownership, and verification data.

## Sovereign Layer Anatomy

High-level layer IDs are not enough. Every layer must expose sublayer, node, transaction, prompt or intent, actor, evidence, and receipt traceability.
